# FineTuned-VisionLLM
Polyglot F1 AI Commentator: Developed a multimodal pipeline using Moondream2 (VLM) and Qwen2.5-1.5B to generate high-energy race commentary across 7 Indian languages. Optimized for real-time latency using AsyncIO and Edge-TTS, delivering automated, localized broadcasts from raw video telemetry.
